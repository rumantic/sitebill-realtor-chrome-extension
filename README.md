# sitebill-realtor-chrome-extension

Расширение для браузера, которое **переносит объявление по ссылке** с Авито, ЦИАН, Домклик, Яндекс.Недвижимости и Юлы
в форму нового объекта на вашем сайте на платформе [Sitebill](https://www.sitebill.ru/import-obyavleniy/).
Вставили ссылку, расширение прочитало открытую страницу объявления и заполнило карточку: цену, площади, адрес,
описание, характеристики и фото. Вы проверяете и публикуете.

> Описание для пользователей и пошаговая инструкция: **https://www.sitebill.ru/import-obyavleniy/**
>
> Статус: **бета**. Квартиры и дома проверены на реальных объявлениях, остальные разделы площадок (комнаты, участки,
> гаражи, коммерция, аренда) подключены по описанию их структуры и дорабатываются.

## Для чего это

Риелтор взял объект в работу по договору с собственником, а объявление у собственника уже висит на площадке.
Вместо того чтобы перепечатывать цену, площади, адрес и описание и заново загружать фото, достаточно указать ссылку.
Подходит агентствам и брокерам, которые переносят свои объекты на собственный сайт, и всем, кто ведёт базу объектов
на платформе.

## Поддерживаемые площадки

| Площадка | Домен | Что распознаётся |
|---|---|---|
| Авито | `avito.ru` | цена, площади, комнаты, этаж, год, адрес и координаты, описание, характеристики, фото |
| ЦИАН | `cian.ru` | то же + адрес по частям (регион, город, район, улица, дом) |
| Домклик | `domclick.ru` | то же + характеристики дома: тип, лифты, парковка, инфраструктура |
| Яндекс.Недвижимость | `realty.yandex.ru` | то же + площади по комнатам, отделка, санузел, вид из окон |
| Юла | `youla.ru` | то же; цену и площади расшифровывает само расширение |

Принимаются только ссылки на **конкретное объявление**: выдача, каталоги и поиск не обрабатываются.

## Только открытая информация

Расширение читает ту же страницу, которую видит любой посетитель, и берёт из неё только поля объявления.

**Переносится:** название, тип объекта и сделка, цена, площади, комнаты, этаж и этажность, год постройки, адрес и
координаты (если продавец их открыл), описание, характеристики, ссылки на фото (сами файлы скачивает сервер вашей платформы).

**Не переносится и не делается:**

- телефоны и другие контакты продавца (телефон в тексте описания удаляется), его имя, рейтинг и профиль;
- логины и пароли, содержимое личных кабинетов: расширение их не запрашивает и не читает;
- выдача и каталоги: одна ссылка — один объект, частота заданий ограничена;
- отправка данных разработчикам или на сторонние серверы: результат передаётся только на страницу вашей платформы.
  Расширение обращается к сайту площадки по указанной ссылке и один раз к вашему сайту при его подключении.

Права браузера: доступ к страницам перечисленных площадок и (после вашего подтверждения, для конкретного адреса) к вашему сайту.
История и закладки не нужны.

> Правила площадок и авторские права на тексты и фото действуют независимо от расширения. Используйте импорт для объектов,
> на которые у вас есть права, например по договору с собственником, и проверяйте итоговую карточку перед публикацией.
> Проект не связан с Авито, ЦИАН, Домклик, Яндекс.Недвижимостью и Юлой; названия принадлежат их владельцам.

## Как это работает

1. Вы вставляете ссылку в блок «Импорт по ссылке» формы нового объекта на своём сайте.
2. Расширение загружает страницу объявления в вашем браузере (с вашими cookie и IP, как если бы вы открыли её сами).
   Если площадка показывает проверку «я не робот», расширение открывает вкладку, вы проходите проверку, и импорт продолжается сам.
3. Из встроенного состояния страницы извлекаются поля объявления; они нормализуются в единый формат (`ImportedListing`).
4. Вы видите предпросмотр, выбираете фото и нажимаете «Заполнить форму». Платформа сопоставляет поля со своей формой,
   справочниками и адресом. Дальше обычная карточка объекта.

Расширение только **извлекает данные**. Сопоставление с полями объекта и сохранение выполняет платформа под вашей сессией;
учётных данных в расширении нет.

## Установка вручную

Расширения пока нет в магазинах браузеров. Подойдёт любой браузер на Chromium (Chrome, Яндекс Браузер, Edge, Opera, Brave);
Firefox и Safari пока не поддерживаются. Есть два способа.

### Способ 1. Готовый архив (проще всего, программирование не нужно)

1. Скачайте архив: **https://sitebill.ru/storage/extensions/chrome-sitebill.zip** (около 50 КБ).
2. Распакуйте его (Windows: правой кнопкой по файлу → «Извлечь всё…»). Получится папка `chrome-mv3`, внутри которой сразу
   лежит файл `manifest.json`. Положите её в постоянное место (например, «Документы») и не удаляйте: браузер читает расширение
   прямо из этой папки.
3. Добавьте расширение в браузер (см. «Загрузка в браузер» ниже) и укажите папку `chrome-mv3`.

Подробная пошаговая инструкция для новичков со схемой папки и разбором частых проблем: https://www.sitebill.ru/import-obyavleniy/#install

### Способ 2. Сборка из исходного кода

Нужен **Node.js 22 или новее**.

```bash
git clone https://github.com/rumantic/sitebill-realtor-chrome-extension.git
cd sitebill-realtor-chrome-extension
npm install
npm run build
```

Без Git: на странице репозитория «Code → Download ZIP», распаковать и выполнить `npm install` и `npm run build` внутри папки.
Результат сборки лежит в `.output/chrome-mv3`.

### Загрузка в браузер

1. Откройте страницу расширений: `chrome://extensions` (Яндекс Браузер: `browser://extensions`, Edge: `edge://extensions`,
   Opera: `opera://extensions`). Адрес нужно вставить в адресную строку: ссылкой он не открывается.
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `chrome-mv3` (из архива) или `.output/chrome-mv3` (если собирали сами).

**Подключение сайта.** Откройте страницу своего сайта на платформе (например, создание нового объекта), нажмите значок
расширения и кнопку **«Подключить этот сайт»**. Сайты на `*.etownpro.ru` подключены автоматически, шаг нужен для собственных доменов.

**Обновление.** Из архива: скачайте новый архив, замените им старую папку и нажмите кнопку обновления на карточке расширения.
Из исходников: `git pull && npm install && npm run build`, затем та же кнопка.

## Разработка

```bash
npm run dev        # сборка с автообновлением, открывает отдельный Chrome
npm run build      # .output/chrome-mv3
npm test           # vitest
npm run typecheck
```

### Структура

- `src/shared/protocol.ts` — контракт (`ImportedListing`, сообщения моста). Копия типов лежит в коде платформы
  (`listingImport.ts`), `PROTOCOL_VERSION` должен совпадать.
- `src/sources/<площадка>/` — адаптеры; `registry.ts` — единый список и allowlist хостов (из него же строятся `host_permissions`).
- `src/platform/` — доверенные сайты (`trust.ts`), подключение домена (`connect.ts`), задание импорта (`importJob.ts`),
  загрузка через вкладку при проверке (`captchaTab.ts`).
- `src/entrypoints/` — `background` (воркер), `platform.content` (мост на страницах платформы), `popup`.

### Как подключается сайт платформы

Известные зоны (`*.etownpro.ru`, `*.sitebill.site`, localhost) подключены статически. Домен пользователя подключается в popup:
запрос разрешения на origin → проверка `/.well-known/etown-extension.json` → динамическая регистрация content script.

### Добавление площадки

1. `src/sources/<id>/index.ts` — `SourceAdapter` (`hosts`, `matchUrl`, `parseHtml`, `load`).
2. Добавить в `ADAPTERS` (`registry.ts`) и в тип `SourceId`.
3. Фикстуры страниц и тесты `extract` / `normalize`.

### Тестовые данные

`tests/fixtures/` — **обезличенные выдержки** из страниц площадок: структура и имена полей настоящие, а адреса, тексты и фото
заменены, идентификаторы объявлений вымышлены, контакты и сведения о продавцах удалены. Страницы проверки («капчи») — упрощённые
заглушки с теми же признаками. Добавляя фикстуру, не кладите в репозиторий сохранённые страницы целиком: в них бывают IP, cookie,
токены и персональные данные.
